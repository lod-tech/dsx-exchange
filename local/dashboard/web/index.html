      Endpoints and credentials for wiring external systems into the local stack. Addresses are shown for in-cluster clients and for host access via kubectl port-forward. Credentials are local-dev defaults. Click any value to copy.

      Completion API — for the EDN system

      OpenAI-compatible HTTP API. Each in-flight request draws the configured per-request power. No auth is enforced on the mock.

      In-cluster base URL
      http://dsx-inference.csc-event-bus.svc.cluster.local/v1
      Via shared gateway
      http://<shared-gateway host>/v1 (gateway shared-gateway in csc-gateway, path prefix /v1)
      From your machine
      kubectl -n csc-event-bus port-forward svc/dsx-inference 8081:80
      http://127.0.0.1:8081/v1
      Endpoints
      /v1/models · /v1/chat/completions · /v1/completions
      Model name
      dsx-mock-llm
      Auth
      None (open endpoint)
      Example
      curl http://127.0.0.1:8081/v1/chat/completions -H 'content-type: application/json' -d '{"model":"dsx-mock-llm","messages":[{"role":"user","content":"hi"}]}'

      DSX Flex over MQTT — for the Energy system (ISV)

      Publish power targets and subscribe to power-state / breach feedback. Messages are CloudEvents 1.0.2 JSON over MQTT, authenticated with an OAuth2 token in the MQTT password.

      Broker (in-cluster)
      tcp://nats.csc-event-bus.svc.cluster.local:1883
      Broker (from your machine)
      kubectl -n csc-event-bus port-forward svc/nats 1883:1883
      tcp://127.0.0.1:1883
      OAuth2 token URL (in-cluster)
      http://event-bus.idp.svc.cluster.local:5556/token
      OAuth2 token URL (from your machine)
      kubectl -n idp port-forward svc/event-bus 5556:5556
      http://127.0.0.1:5556/token
      Client ID / secret
      grid-isv / grid-isv-secret
      OAuth2 scope / grant
      mqtt · client_credentials
      MQTT username / password
      oauthtoken / <access token>
      Publish (set power target)
      grid/v1/isv/<isv-id>/loadtarget/set e.g. acme-energy
      Subscribe (feedback)
      grid/v1/dsx-flex-agent/maxlps/powerstate/status
      grid/v1/dsx-flex-agent/maxlps/powerbreach
      CloudEvents
      type grid.loadtarget.set.v1 · source //grid/v1/isv/<isv-id> · feed ai-factory-main
      Reference CLI
      make set-load-target (local/inference-mock/cmd/set-load-target)
